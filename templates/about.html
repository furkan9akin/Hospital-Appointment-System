About This Project

The Hospital Appointment System is a web application developed to explore backend development, database design, and appointment-management workflows using Python.

Project Features

  • Patient record management
  • Doctor record management
  • Appointment scheduling
  • Appointment status tracking
  • Dashboard statistics
  • Upcoming appointment overview

Technologies

  • Python
  • Flask
  • SQLite
  • HTML
  • CSS

Project Context

This project was originally developed as a final project during the Kodland Python Level 3 program and was later organized as a software portfolio project.
